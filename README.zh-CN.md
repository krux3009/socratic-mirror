# 苏格拉底之镜 · 学习工具 (socratic-mirror)

把任意一个概念，变成一份**可交互的 HTML 学习页**：先用**两个**表面不相干、底层却是同一台机器的**寓言**把概念间接讲懂，让你**先从选项里认出它们共享的机制**、结尾才点破，再用一连串**即时反馈的选择题**逐层自测（理解 → 常见漏洞 → 辨别比方 → 迁移应用），最后用**翻卡**做主动回忆。每道题点一下就锁定，立刻告诉你对不对、为什么；错答当场被点破。

> 像苏格拉底那样，它不直接把答案塞给你，而是把你自己的理解照回给你看。
> 适合学生、自学者，以及任何"一看就会、一做就废、过两天全忘"的人。

## 为什么需要它

只让 AI 讲、你点头，是最常见的**能力错觉**——眼熟 ≠ 懂得。反复重读只会强化这种错觉；而**逐题强制判断 + 当场纠错**能把它戳破。本工具把每个互动阶段都做成选择题，干扰项建立在这个概念**真实的误区**上——你一选错，立刻被抓出来、被点破；每个阶段不答完不放行。背后是几条被反复验证的学习原理：**类比迁移**（两个同构故事逼你抽象结构、不背表皮）、**测试效应 + 即时反馈**（带纠正反馈的判断练习比重读记得牢）、**主动回忆**（翻卡）。

> 说明：本版**没有自由文本作答**，是"识别 + 即时反馈"路线。故不声称"自我解释"那条效应——那需要学习者自己产出长解释。

## 七个阶段

**两个故事**（同一台机器，毫不相干的两层皮）→ **猜共性**（点名之前，先从选项里认出它们共享什么机制——这正是"两个故事胜过一个"的原因：逼你剥掉表面、只抓结构）→ **揭晓**（点破概念，把两个故事都映射回机制）→ **自测**（理解选择题）→ **查漏洞**（专挑最容易搞反、被术语糊弄的点）→ **辨比方**（选出真正同构的那个比方，反馈告诉你坏的崩在哪、好的边界在哪）→ **主动回忆**（翻卡）**+ 迁移挑战**（把概念用到一个全新场景）。

每道选择题点一下就锁（先承诺、再看理由），门槛 = **全部答完，不是全对**（错选的『为什么』已经把误区讲掉了）。进度自动存在本机浏览器。

> 为什么是两个寓言？一个故事会把概念**绑在它的表皮上**（"比较优势＝那个厨师的故事"）。两个结构相同的故事 + 一句"它们共享什么"，逼你抽象出**可迁移的结构**——这是类比迁移的经典杠杆。

## 功能特性

- **双寓言对照 + 猜共性** — 在点名之前，跨两个不相干的故事认出共享机制，逼你抽象结构、而非记住表皮。
- **全程选择题 + 即时反馈** — 每个互动阶段都是选择题，选错当场点名误区；干扰项针对该概念、不放废选项。
- **阶段门槛** — 一个阶段的题没答完，不让进下一关。
- **完全自包含** — 单个 HTML 文件，离线可用，无需 API key、无外部依赖。
- **键盘 + 读屏友好** — `←`/`→` 切换阶段，步骤条是真正的 ARIA tablist，选项是 ARIA radiogroup，卡片用 `Enter`/`空格` 翻面。
- **一键打印 PDF** — `⌘`/`Ctrl`+`P` 把所有阶段（你的选择 + 正确答案 + 解释）展开成一份干净、可存档的做完页。
- **自动存档** — 进度与作答存在本机浏览器，关掉再开继续。

## 安装

```bash
openclawmp install skill/socratic-mirror --target-dir ./skills
```

## 用法

1. 触发：`/learn 比较优势`（或 `/feynman <概念>`、自然语言"教我 X / 帮我学懂 X"）。
2. 概念太宽时，它最多问你 1–2 个问题把题目收窄。
3. 它生成 `./<概念>.html`，用浏览器打开，一步步走完七阶——每个阶段要全部答完才放行，错了当场告诉你为什么。

## 配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 难度 | `undergrad` / `grad` / `research` | `grad` |
| 领域 | 概念所属领域（决定寓言取材） | 自动推断 |
| 输出语言 | 跟随你给的概念语言（中 / 英） | 自动 |
| 输出位置 | 生成的 HTML 存放路径 | 当前目录 |

## 设计理念：先认结构，即时纠错

两个寓言负责"编码"（用结构而非表皮把概念讲进脑子），逐层选择题负责"诊断"（在你真正会翻车的地方当场抓出来、当场修）。费曼四步仍在——但作为**选题的镜子**（讲简单→理解题、找漏洞→漏洞题、打比方→比方题，再加迁移题），不是自由作答的形式。取代旧"先写才解锁"那道锁的新纪律：每题都得答、先承诺再看理由、错了被教而不只是被标记。
