# 概念备料 — 怎么切窄、怎么写脚手架（Concept Prep）

> 本文件指导：把概念切成一个可学透的窄片，并写出**针对该概念**的五组选择题（猜共性/理解/漏洞/比方/迁移）+ 翻卡。

## 一、把概念切窄

太宽的题目会让寓言和解释都变空泛（费曼第一大坑）。学习者给的往往是一个学科或大主题——你的任务是收窄到一个**机制级**的切片。

| 太宽 ❌ | 切窄 ✅ |
|---|---|
| 机器学习 | 反向传播里"梯度沿链式法则回传"这一步 |
| 经济学 | 比较优势：为什么绝对劣势方仍能从贸易获益 |
| 量子力学 | 叠加态测量为什么会"坍缩"成一个本征值 |
| React | 为什么 inline 对象 prop 会触发子组件重渲染 |

判断标准：一个切片应该能用**一个寓言 + 一个比方**讲透。如果你发现要塞进三个机制，说明还要再切。概念太宽时，在 Step 1 澄清门**问学习者想先攻哪一块**。

## 二、写选择题：五组共用的心法

v1.3 起所有互动都是选择题（五组：predict / comprehension / gaps / analogy / transfer），共用同一形状、同一套写法铁律：

**1. 题干 = 承重关系 / 应用，不是定义。**
- 差 ❌：「比较优势的定义是？」（认得即可，测不出理解）
- 好 ✅：「决定贸易方向的是绝对优势还是比较优势？」

**2. 干扰项 = 被实体化的误区**。别放"明显错的废选项"——放学习者**真会信**的错误心智模型。例（比较优势）：

| 选项 | 它是什么 |
|---|---|
| 机会成本最低 → 分工总产出更大 ✅ | 正确机制 |
| 靠补贴压价 ❌ | 把贸易获益误当价格战 |
| 攒顺差囤黄金 ❌ | 重商主义直觉 |
| 劳动力便宜、绝对成本低 ❌ | 绝对优势 ≠ 谁该生产 |

**3. `whyWrong` 是错选时的教学载荷**——一句话，**点名这个误区 + 给出正确机制**，不是通用鼓励/责备。`whyCorrect` 同理：一句针对该概念的话说为什么对，不是"答对了！"。
- 差 ❌：「不对，再想想。」（通用废话，没教任何东西）
- 好 ✅：「把贸易获益误当价格战；机制是机会成本差异，不是补贴。」

**4. 门槛 = 全部答完，不是全对**——错答是教学时刻，所以干扰项要"错得有营养"（`whyWrong` 就是营养所在）。

## 三、五组分别要挖什么

- **predictChecks**（Reveal 前 · 1–2 题）：让学习者**认出两个故事共享的机制**。正确项 = 共享机制的大白话；干扰项 = 只抓表面话题 / 抓错机制。⚠ 题干和选项**绝不能点出 term 的正式名字**。
- **comprehensionChecks**（Reveal 后 · 3–5 题）：考核心承重关系，确认"点破"之后真的接住了。
- **gapChecks**（3–5 题）：专挑这个概念**最容易翻车**的点。四把尺找题源：
  - **反直觉的一步** —— 机制里违反常识、最容易想当然的环节。
  - **符号/方向容易反** —— 哪个增哪个减、谁导致谁、正负号。
  - **术语糊弄区** —— 一用某个术语就以为讲清了，其实没拆开。
  - **边界条件** —— 什么时候成立、什么时候失效。
- **analogyChecks**（1–3 题）：给几个候选比方，选**真正同构**的那个。干扰项是"表面像、骨子里错"的比方；`whyWrong` 点明它在哪儿崩，`whyCorrect` 点明对的那个**在哪儿也会失效**（好比方也有边界）。
- **transferChecks**（1–3 题）：**迁移**到一个新场景，选正确的**应用**，不是复述。
  - 复述 ❌：「再讲一遍比较优势是什么。」
  - 迁移 ✅：「一位外科医生同时也是全院打字最快的人——病历该谁打？」（选项里埋"绝对优势陷阱"当干扰）
  - 好的迁移场景：表面和原概念不同，底层是同一机制；只有真懂才选得对。

## 四、写卡片（flashcards）

页面上唯一保留的非选择题互动（翻面 + got/again 自评）。考**承重的关系**，不考能眼熟的定义。5–8 张。

- 差 ❌：「Q: 比较优势的定义？」（认得即可，测不出理解）
- 好 ✅：「Q: 决定贸易方向的是绝对优势还是比较优势？ A: 比较优势——看的是相对机会成本，不是谁绝对更强。」
