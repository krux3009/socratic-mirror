# 概念备料 — 怎么切窄、怎么写脚手架（Concept Prep）

> 本文件指导：把概念切成一个可学透的窄片，并写出**针对该概念**的漏洞清单、卡片、教学挑战。

## 一、把概念切窄

太宽的题目会让寓言和解释都变空泛（费曼第一大坑）。学习者给的往往是一个学科或大主题——你的任务是收窄到一个**机制级**的切片。

| 太宽 ❌ | 切窄 ✅ |
|---|---|
| 机器学习 | 反向传播里"梯度沿链式法则回传"这一步 |
| 经济学 | 比较优势：为什么绝对劣势方仍能从贸易获益 |
| 量子力学 | 叠加态测量为什么会"坍缩"成一个本征值 |
| React | 为什么 inline 对象 prop 会触发子组件重渲染 |

判断标准：一个切片应该能用**一个寓言 + 一个比方**讲透。如果你发现要塞进三个机制，说明还要再切。概念太宽时，在 Step 1 澄清门**问学习者想先攻哪一块**。

## 二、写"针对该概念的"漏洞清单（gapChecklist）

通用废话（"你讲清楚了吗？"）没用。要挖出**这个**概念里学习者最容易翻车的点。去这些地方找：

- **反直觉的一步** —— 机制里违反常识、最容易想当然的环节。
- **符号/方向容易反** —— 哪个增哪个减、谁导致谁、正负号。
- **术语糊弄区** —— 一用某个术语就以为讲清了，其实没拆开（让学习者**不用那个词**重讲一遍）。
- **边界条件** —— 什么时候成立、什么时候失效。

每条写成一句**学习者能自评**的提问，4–7 条。例（比较优势）：
- "能不能解释：为什么一个国家**什么都做得差**，却仍然能从贸易里获益？"
- "不用'成本'这个词，说清楚这里的'机会成本'在干什么。"

## 三、写卡片（flashcards）

考**承重的关系**，不考能眼熟的定义。5–8 张。

- 差 ❌：「Q: 比较优势的定义？」（认得即可，测不出理解）
- 好 ✅：「Q: 决定贸易方向的是绝对优势还是比较优势？ A: 比较优势——看的是相对机会成本，不是谁绝对更强。」

## 四、写教学挑战（teachBackPrompt）

终极一关：给一个**新场景**，逼学习者把机制**迁移**过去，而不是复述。

- 复述 ❌：「再讲一遍比较优势是什么。」
- 迁移 ✅：「一位外科医生同时也是全院打字最快的人。用你刚学的，解释病历该谁来打。」

好的 teach-back 场景：表面上和原概念不同，但底层是同一个机制；学习者只有真懂才能套上去。
