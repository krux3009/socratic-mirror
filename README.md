# 寓言 + 费曼学习工具 (parable-feynman-tutor)

把任意一个概念，变成一份**可交互的 HTML 学习页**：先用一个**寓言**把概念间接讲懂（结尾才点破是什么），再用**费曼技巧**逼你自己讲一遍、找出知识漏洞、打个比方、做主动回忆。所有标准答案在你写下自己的解释之前一直**锁着**——逼你输出，而不是看着眼熟就以为懂了。适合学生、自学者，以及任何"一看就会、一做就废、过两天全忘"的人。

> 设计内核：**先输出，再揭晓（produce before reveal）。** 只让 AI 讲、你点头，是最常见的"能力错觉"。本工具把"先凭记忆讲一遍"写进了代码（reveal-gate）。

## 功能特性

- **寓言编码** — 用故事把抽象概念讲活，领域/术语结尾才揭晓（源自 Amanda Askell 的"寓言提示词"）。
- **费曼六阶** — 寓言 → 揭晓 → 你来讲 → 找漏洞 → 打比方 → 主动回忆 + 教学挑战。
- **答案带锁** — 写够一段自己的解释，范例答案才解锁。
- **复制评分提示词** — 一键把"你的作答 + 评分指令"拷进剪贴板，粘到任意 AI 对话（StepFun 阶跃 / Claude 等）拿即时点评；只诊断、不替你写。
- **自动存档** — 进度与作答存在本机浏览器，关掉再开继续。
- **完全自包含 + 离线** — 单个 HTML 文件，无需 API key，无外部依赖。

## 安装

```bash
openclawmp install skill/parable-feynman-tutor --target-dir ./skills
```

## 使用方法

1. 触发：`/learn 比较优势`（或 `/feynman <概念>`、`/parable <概念>`、自然语言"教我 X / 帮我学懂 X"）。
2. 概念太宽时，它最多问你 1–2 个问题把题目收窄。
3. 它生成一份学习页 `./<概念>.html`，用浏览器打开。
4. 一步步走完六阶——记住：标准答案在你动手写之前是锁着的。
5. 想要即时点评时，点"复制评分提示词"，粘到你的 AI 对话里。

## 配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `difficulty` | 难度：`undergrad` / `grad` / `research` | `grad` |
| `domain` | 概念所属领域（决定寓言取材） | 自动推断 |
| 输出语言 | 跟随你给的概念语言（中/英） | 自动 |
| 输出位置 | 生成的 HTML 存放路径 | 当前目录 |

## 依赖

- OpenClaw / StepClaw 运行环境
- 生成的 HTML 页无任何运行时依赖（任意现代浏览器，可离线打开）
